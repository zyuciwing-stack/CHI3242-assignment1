# 詞典補充分詞與重跑說明（qi_scope_v4_dict）

本文件只記錄本輪實際執行的方法、參數與核驗結果。文學詞義裁定、詞義分類與學生正式報告由使用者完成；AI 未代寫。

## 一、詞典原檔與來源

- 原檔：工作區根目錄 `古代汉语词典.txt`，由教師提供；**未有書目／製作資料**，目前只能記錄為「教師提供的詞目表」，不推定某部出版詞典的版本、時代覆蓋或準確率。
- 格式核查（實測）：UTF-8 無 BOM、LF 換行、末行有換行、無空行；1,625,712 bytes；200,826 行＝200,826 唯一詞目；無詞頻、無詞性、無釋義；**505 個含標點詞目**（例：江山易改，禀性难移）仍保留、不刪內部標點後拼接。
- 名稱雖為「古代漢語詞典」，內容包含近現代詞目；詞典缺少若干人名（如「越石」「王粲」未入表）。以上皆照實記錄，不判定不可使用，亦**不宣稱古代漢語已準確適配**。
- SHA-256（原檔與副本一致）：`d8922e2aeb42f7dd8317da60aea07be8b99ac8bb2e740956329df0d0c27154c7`。
- 原檔逐字節複製至 `resources/dictionaries/古代汉语词典_original.txt`，工作區根目錄原檔未動。

## 二、詞典派生與載入政策

- 派生：OpenCC t2s 0.1.7 逐行轉換、保留原行序；轉換後同形詞目只保留第一次出現。實測：**966 行字形改變、70 行形成重複**，派生表 **200,756** 詞目；全轉換／合併對照存 `resources/dictionaries/ancient_words_t2s_conversion_log.csv`。
- 派生表：`resources/dictionaries/ancient_words_t2s.txt`（UTF-8 無 BOM、LF、末行換行）；SHA-256＝`d5f6e7694e3c71786232cbdad09b535ed5af730bd793a447e9476c42baa6eeff`（與預檢指定值一致）。
- 載入：**獨立 `jieba.Tokenizer()`，在任何本輪分詞之前 `initialize()` 再 `load_userdict(派生表)`**；保留 jieba 0.42.1 預設主詞典（未用 `set_dictionary()` 取代），同一個已載入詞典的 Tokenizer 用於全部 128 單元（含零命中背景單元）。jieba 主詞典 SHA 已記入 `resources/preprocessing_lock.json`。
- 頻次政策：詞目未提供詞頻，採用 **jieba 原生省略詞頻的自動推算**；導入順序為鎖定派生表行序。明記：這些推算值是**分詞權重，不是研究語料的實際頻數**；未任意統一指定巨大頻次、未按結果調整頻次。
- `resources/preprocessing_lock.json` 記錄原檔／派生表／jieba 主詞典 SHA、來源與日期、OpenCC／jieba 版本、轉換／去重／行序／頻次政策、Tokenizer、HMM 及腳本 SHA。既有來源 `input_lock.json` 不改；兩部分鎖定分別核驗。

## 三、全面重新分詞（禁止沿用）

- 本輪腳本**全面禁用** v3 的 reuse_roots／try_reuse／validated_v21_reuse 等沿用分支；128 單元全部以詞典分詞器實際重建，`reused_units=0`，逐單元記錄 `mode=rebuilt_with_userdict` 與詞典雜湊（`output/unit_verification.csv`）。
- 其餘前處理規則與 v3 完全一致：正文 OpenCC t2s、default 模式、HMM=True；同一分句／換行規則（。！？；…及換行）；去純標點／空白；既定 136 條引詩標記（55 條 excluded=1）硬邊界不跨界不拼接；文論重引保留；零命中材料保留作背景。
- **「气」定向切分保留**：即使詞典列有骨气／体气／辞气，每個气字符仍按其位置切出為單獨目標 token（研究規則不改）；未額外強拆文／書／體等其他字。
- 目標位置守恆核驗：106 個保留气位置與 v3 一一對應（實際計得，非硬寫常數）；字串重建、來源／句段／引詩邊界逐單元核驗通過。

## 四、qhchina 六組分析

- 背景（本輪新 tokens 實算）：128 單元；非空保留句段 **3,966**（與 v3 相同，因句界不變）；全部 token **35,411**（v3 為 35,138）；保留气目標 **106**；零命中單元 87。
- N／R1：window N_fisher=35,305、R1=734（w5）／1,047（w10）；sentence N=3,966、R1=102。
- 正式組：`min_word_length=2`、`max_p=0.05`、原 40 詞停用詞（僅結果篩選、仍佔窗口）；列數 **340／406／509**。
- 補充組：`min_word_length=1`、`stopwords=[]`；40 詞快照繼續作參考並核驗，日誌區分「參考清單 40 項」與「實際套用 0 項」；列數 **381／447／569**（單字 41／41／60）。本輪入表原停用詞：之（w10=32、sentence=29）、以（sentence=11）、则（sentence=12）、其（sentence=8）等。
- 兩組各實際執行 window horizon=5、window horizon=10、sentence；`target_words=["气"]`、`alternative="greater"`、`correction=None`、`sort_by="obs_local"` 降序、`max_sentence_length=256` 明示核驗（本輪最大句段未超限）。
- 六表**逐列**獨立核驗 obs／C1／exp=R1×C1/N／ratio／scipy Fisher 單尾 greater p，並核對顯著結果清單完整性；例句均取自本輪實際共現事件。補充表字長≥2 的列與本輪正式表七欄完全一致（340／406／509）。

## 五、分詞變化與詞典作用核讀

- 彙總（實算）：舊 35,138 → 新 35,411 token；**1,398** 句段分詞變更；**121** 單元有變更；106 個气位置全數保持；按气位置口徑 **45** 個位置所在句段分詞有變更（按含氣句段口徑為 43 個；差額來自〈養氣〉兩個各含兩次气的變更句段）。
- 對照檔（以原字元範圍對齊，不用新舊 token_index）：`output/tokenization_changes.csv`（全庫逐句段，3,989 行＝3,966 非空句段＋23 個空 token 段）、`output/qi_context_tokenization_comparison.csv`（106 個目標位置逐例，orig_char 為原文字形「氣」）、`output/tokenization_summary.csv`（逐單元彙總）。
- 重點例句（舊→新）：
  - 詩品「骨氣奇高，詞采華茂」：`骨/气/奇高/词/采华茂` → `骨/气/奇高/词采/华茂`——**「詞采／華茂」已修正**（詞采入派生表）。
  - 詩品「劉越石仗清剛之氣」：`刘越/石仗/清刚/之/气` → **不變，「劉越／石仗」未修正**（詞典無「越石」）。
  - 典論「徐幹時有齊氣」：`徐干时/有/齐/气` → `徐/干时/有齐/气`——**「徐幹時」仍有錯切，並本輪新增疑似錯切「干时／有齐」**。
  - 典論「文以氣為主」：`文以/气/为主` → 不變。可陳述的判斷僅為**氣目標落點正確**；`文以` 與 `为主` 的周邊詞界仍待原文核讀，不能稱整句詞界已正確。
- 既有疑切（**v3 正式表已存在、本輪未修**，不屬詞典新增）：`肇自血`（w5 obs=2，v3／v4 相同）、`之匹`、`云时`。本輪新變化（另記）：`干时`、`有齐`、`词采`、`华茂` 等入表詞項。切分變化不等於準確率提升；未輸出未經人工標準答案驗證的準確率。

## 六、與 v3 的關係與解讀限制

- `qi_scope_v3` 仍是原通用 jieba 基線（正式 332／409／511、補充 381／457／578），本輪未修改其任何檔案；比較只在**相同詞長／停用詞設定**下進行（正式對正式、補充對補充），不把詞典、詞長與停用詞三項差異混為單一原因。
- 詞典缺少人名／出現近現代詞目不等於不可使用，但不宣稱古代漢語已準確適配；詞典也不代表完成文論概念辨義。
- p 值為未校正 Fisher 單尾探索結果（correction=None），顯著列不是詞義分類或文學結論。
- 本輪結果**不立即替換**提交版本（`CHI3242-assignment1` 未動、未同步、未覆寫）。

## 七、AI 使用與核驗

- 使用者：提供詞典原檔與本輪指令；詞典來源／製作資訊由使用者補充；文本核讀、詞義裁定與正式報告由使用者完成。
- ChatGPT 預檢：僅重分詞預覽（35,411 token、1,398 句段、121 單元、106 位置、45 位置所在句段變化），未跑 qhchina；本機實跑與預檢一致（按气位置口徑 45；按含氣句段口徑 43，兩口徑均已記錄）。
- OpenCode 本地（DeepSeek Pro）：本輪詞典派生、腳本改寫（禁沿用＋詞典 Tokenizer）、六組分析執行與核驗、頁面與報告。
- 核驗通過：`--verify-inputs`（既有來源鎖定）與詞典鎖定（原檔／派生表／jieba 主詞典 SHA）雙通過；reused_units=0、128 單元全部重建；六組 qhchina 全部實際執行；HTML 與六張 CSV 逐列一致、例句可回查、相對連結可解析。
